# AI Chat & Minigames Web Application

A full-featured web application with user authentication, AI chatbot, and 15 playable minigames.

## Features

### 🔐 Authentication
- User login and signup
- Secure password authentication
- Local storage for user data

### 💬 AI Chat
- Interactive chatbot interface
- Real-time messaging
- User-friendly chat UI

### 🎮 15 Minigames
1. Memory Match
2. Flappy Bird
3. Tic Tac Toe
4. Snake Game
5. Rock Paper Scissors
6. Whack a Mole
7. Quiz Master
8. Simon Says
9. Puzzle Game
10. 2048
11. Maze Runner
12. Catch Game
13. Dice Roller
14. Word Scramble
15. Trivia Game

## How to Use

1. **Open the application** in your web browser
2. **Sign up** with your credentials or **login** if you have an account
3. **Chat with AI** - Ask questions in the chat box on the left
4. **Play Minigames** - Click on any game card to start playing
5. **Logout** - Click the logout button to exit
